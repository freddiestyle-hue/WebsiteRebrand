First principles

Six rules that decide every other rule.

  1. Restraint is the brand.

    The palette is small, the type kit is small, the icon set is small, the component library is small. If a problem can be solved with what's already in the system, the answer is to use it. Inventing new tokens, new colours, or new components is a last resort and requires a commit.

  2. Geometry is square.

    Default radius is zero. Hairlines are 1px. Stroke caps are square, joins are mitre. The only allowed curve is the dot mark and the pill stamp. Rounded corners read as web-app slop and are forbidden on chrome.

  3. The italic is the whisper, never the statement.

    Newsreader italic carries the second clause of a thought, never the first. It runs in --ink-dim on light, --on-ink-italic on dark. It is not bold, it is not full-sentence, and it does not appear in buttons, stamps, or labels.

  4. Numbers do the persuading.

    Specific numbers — £12k, 30 markets, 14 days — replace adjectives. Two-digit zero-pad in mono labels: 01, 02. En-dash for ranges only. Numbers are voice.

  5. Tokens, not values.

    Every spacing, colour, type, motion and radius value in component CSS routes through a token. Raw #hex, raw px, and raw ms in component code are bugs. The token file is the contract.

  6. The page is the proof.

    Every component, pattern, and template in the system has a working example you can read the source of. No screenshots, no Figma-only specs. If it isn't a working page, it isn't shipped.

How to use →

Three ways in. Pick the one that matches the question.

The system serves three audiences: the operator shipping a page, the writer drafting a post, the founder briefing a contractor. Each lands in a different door.

If you are shipping a page

Start at Foundations for tokens. Pull the tokens.css stylesheet. Compose with Components and Patterns. If the page is one of the eight named kinds, copy the matching Template.

If you are writing copy

Read Voice first, then the relevant Template microcopy. The italic rule, the numbers rule, and the no-marketer-words list are non-negotiable.

If you are briefing a contractor

Send design.md, this hub URL, and the relevant template. Anything not in those three documents is out of scope until it lands in the repo.
