# Rivett Icons

Production Astro components extracted from `design-spec-v2/icons.html` per `CC-BRIEF-ICONS.md`.

- Slugs: ico-diagnostic, ico-pipeline, ico-signal, ico-approval, ico-memo, ico-operator, ico-stack, ico-outreach, ico-decline, ico-cadence, ico-numbers, ico-halt.
- Sizes: 16, 20, 24, 44.
- Stroke: `currentColor`, `1.6`, square caps, miter joins.
- Dot icons use `fill="var(--accent)"` and no stroke.

Use icons with a visible label or inside an icon button whose button carries the accessible name. The SVGs are decorative by default with `aria-hidden="true"`.
